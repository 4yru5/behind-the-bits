# Behind the Bits

Small Python scripts that show how text is represented by computers.

- `string-to-ascii.py` prints each character's ASCII value.
- `string-to-binary.py` shows each character's 8-bit binary form and how its bits add up.

## Run

Requires Python 3. From the repository directory, run either script:

```bash
python3 string-to-ascii.py
python3 string-to-binary.py
```

Enter a string when prompted. Characters outside the ASCII range are identified as `not ASCII`.
